# Mini Benchmarker Report (Normal 100us Mode)

This report covers the standard cyclictest latency benchmark across schedulers
for `scx_flow v2.2.2`.

Run: `20260508_104621`  
Mode: `cyclictest -D 30 -t 4 -a 0 -m -v` (4 threads on CPU 0, 1ms interval)

## Results

| Scheduler | Max Latency (us) | Spikes >100us |
|-----------|-----------------|---------------|
| baseline | 1114 | 642 |
| scx_cosmos | 860 | 1477 |
| scx_bpfland | 3206 | 1335 |
| **scx_flow v2.2.2** | **299** | **18** |

scx_flow v2.2.2 dominates with the lowest max latency (299us) and
dramatically fewer spikes over 100us (18) compared to all competitors.
