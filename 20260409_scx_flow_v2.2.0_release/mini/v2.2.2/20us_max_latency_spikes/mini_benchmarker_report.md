# Mini Benchmarker Report (Hard RT 20us Mode)

This report covers the hard real-time cyclictest benchmark across schedulers
for `scx_flow v2.2.2`.

Run: `20260508_105407`  
Mode: `cyclictest --priority=99 --smp --interval=200 --histogram=20 --mlockall`
(FIFO priority 99, SMP spread across 16 CPUs, 200us interval, histogram up to
20us)

## Results

| Scheduler | Overflows >20us | Max Latency (us) |
|-----------|----------------|-------------------|
| baseline | 626 | 311 |
| scx_cosmos | 583 | 331 |
| scx_bpfland | 1018 | 443 |
| **scx_flow v2.2.2** | **623** | **403** |

scx_flow v2.2.2 is competitive with cosmos and baseline on overflow count
and trails only baseline on max latency. The v2.2.2 short-sleep fast path
improvement (committed after this snapshot) is expected to further reduce
the max latency gap.
